# CÓMO DESCARGAR LOS ARCHIVOS DEL PROYECTO

## OPCIÓN 1: Descargar desde GitHub (Recomendado)

### Método A: Descargar ZIP completo del repositorio

1. Ve a tu repositorio: `https://github.com/Miguel-91/Telecomunicaciones`
2. Click en el botón verde **"Code"**
3. Click en **"Download ZIP"**
4. Descomprimir el archivo

### Método B: Descargar rama específica con las configuraciones

1. Ve a: `https://github.com/Miguel-91/Telecomunicaciones/tree/claude/setup-repository-01FqkTXKtKd33ti6gQ5BeuMU`
2. Click en **"Code"** → **"Download ZIP"**
3. Descomprimir

### Método C: Clonar el repositorio (si tienes Git instalado)

```bash
git clone https://github.com/Miguel-91/Telecomunicaciones.git
cd Telecomunicaciones
git checkout claude/setup-repository-01FqkTXKtKd33ti6gQ5BeuMU
```

## OPCIÓN 3: Desde la línea de comandos (si tienes acceso)

Si tienes acceso al servidor donde están los archivos:

```bash

cd /home/user/Telecomunicaciones

# Copiar solo lo necesario a tu directorio local
cp -r configs_limpias/ /tu/directorio/destino/
cp LEER_PRIMERO.txt /tu/directorio/destino/
```

## ¿PROBLEMAS PARA DESCARGAR?

Si tienes problemas:

1. **Acceso denegado**: Asegúrate de tener acceso al repositorio
2. **Rama no encontrada**: Usa la rama principal o descarga todo el repo
3. **Archivos corruptos**: Vuelve a descargar
4. **No tienes Git**: Usa la opción de Download ZIP desde GitHub
